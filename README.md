# Klasifikasi-Citra-Emosi-Wajah-Menggunakan-CNN
klasifikasi citra emosi wajah berbasis Deep Learning menggunakan Convolutional Neural Network (CNN). Proyek ini dikembangkan dengan TensorFlow, Keras, dan Streamlit untuk mengenali berbagai ekspresi wajah secara otomatis melalui antarmuka web yang interaktif.
